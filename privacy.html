Privacy policy

Last updated: 2026-11-24

What the app accesses

With the user's permission, My Calendar uses these Google API scopes:

  • calendar.calendarlist.readonly: read the list of calendars
  • calendar.settings.readonly: read calendar settings (week start, time zone)
  • calendar.events: read, create, edit, and delete calendar events
  • tasks: read, create, edit, and delete tasks, and mark them complete

How data is used and stored

  • Calendar and task data is used only to display and edit it in the app on the user's own Mac.
  • To show the calendar quickly at launch, the app keeps a copy of recently viewed calendar data (calendar list, events and tasks) on the user's Mac, encrypted with a key kept in the macOS Keychain. This copy is replaced with fresh data from Google each time the app opens, and it is deleted when the app's Google sign-in ends (for example, after access is revoked).
  • The sign-in token is stored on the user's Mac, encrypted with a key kept in the macOS Keychain.
  • The app talks only to Google's servers. It has no server of its own, and it sends no data to the developer or to any third party.
  • No data is sold, shared, or used for advertising.

My Calendar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. After access is revoked, the app deletes the stored token and the cached calendar copy the next time it tries to reach Google.
